    ace-jax¶

    ace-jax builds, fits and evaluates Atomic Cluster Expansion (ACE) interatomic potentials in Python with JAX. One pip install gives all of these functions. It also evaluates pacemaker PACE .yace potentials.

    • Fit from data with one command. aj fit --order 3 --max-degree 10 ... builds the ACE basis for the species in your data and fits it. The fit is a Bayesian linear regression: the evidence sets the weights and the regularisation. Each fit writes a fit.yaml file that runs it again.
    • Build a basis on its own with aj basis. You can then save it, share it or fit it again.
    • Learn the radial basis by variable projection. For deployment, the learned radials become splines, so they are as fast as a stock model.
    • Evaluate with aj eval, or in Python with the ASE calculator ACECalculator.
    • Deploy to LAMMPS with lammps-jax.
    pip install ace-jax

aj fit --order 3 --max-degree 10 \
    --train train.xyz --test test.xyz \
    --e0 lsq --opt lbfgs \
    --out fit
aj eval --model fit/model.npz --data test.xyz --out predictions.xyz

    The Quickstart runs these commands on a small silicon dataset. The tutorials are marimo notebooks. You can run them on your computer or open them in molab.
