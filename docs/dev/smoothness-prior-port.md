# The algebraic smoothness prior, ported from Julia

**Goal.** Compute ACEpotentials.jl's `algebraic_smoothness_prior` in pure numpy
(`ace_jax/construct/prior.py`), so a fit can proceed when an exported `.npz`
lacks `gamma` — and so future authoring paths can emit it themselves. Refitting
or evaluating an existing exported model stays 100% Julia-free.

**What it computes, and why bit-for-bit is possible**, is documented once, in
the `prior.py` module docstring: the Julia formula and its constants, the
`[tensor x NZ | pair x NZ]` column layout, the embedded-model radial-index
fold, the unported `_coupling_scalings` branch, and why `meta["nnll"]` is the
only viable source of the tensor bodies. This page covers only what the
docstring does not: how the port is verified and wired in.

## Verification pyramid

1. **Formula** — `tests/test_smoothness_parity.py` feeds the port the oracle's
   own inputs: four committed fixtures
   (`fixtures/smoothness_ref_*.npz`, orders 2-4, 2-3 species, incl. the
   degenerate-block `wL = 0.5` shape) generated by
   `julia/smoothness_reference.jl`, storing `gamma` together with the FULL
   per-column nnll basis. Compared bit-for-bit (a tolerance would hide a
   convention drift), plus the block-order, species-replication and constancy
   contracts read off the same fixtures.
2. **End-to-end** — `fixtures/si_fitted.npz` stores the gamma
   `algebraic_smoothness_prior` returned on the real model;
   `gamma_from_model` must reproduce it bit-for-bit from `meta["nnll"]` alone.
   The other ship exports (analytic radial, big basis, the NZ=2 `sige_nofit`
   refit target) are covered structurally (length vs the exporter's
   `len_basis`, positivity, species replication, pair values `n^4`).
3. **Embedded models** — no ship fixture is an embedding export, so the
   radial-index fold is tested from a real NZ=2 meta with a synthetic
   `meta["embedding"]` against an independent evaluation of the Julia formula.

## Wire-in

`cli.py` and `bench/acegp_cantor/run.py` both call `prior_diagonal(z, meta,
path)`: an exported `gamma` is authoritative and used verbatim; otherwise gamma
is rebuilt via `gamma_from_model(meta)` with a log line naming the file. An
export that predates the `nnll` meta dump fails with a `ValueError` saying to
re-export. Nothing else in the eval/fit path changed.

## CI

The `prior-parity` workflow (`.github/workflows/prior-parity.yml`) regenerates
the four oracle fixtures with Julia 1.11, fails if they differ from the
committed ones (the committed files are what pip-only `test.yml` tests
against), and re-runs the parity tests. It runs on every push touching the
port, its tests, the oracle script, the fixtures or the workflow itself, and
weekly. Fixtures are committed, so pip-only environments never need Julia.
