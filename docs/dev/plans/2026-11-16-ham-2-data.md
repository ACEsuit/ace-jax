# Hamiltonians 2: data layer (DeepH IO, conventions, ingestion) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Operator data from Quoll.jl reaches ace-jax in ace-jax's own orbital convention, with that convention proven on real data.

**Architecture:** `ace_jax.ham` starts as a leaf package behind the `ham` extra. A pure-Python reader and writer handle the DeepH layout; a Julia script under `ham/julia/` runs Quoll for every other source and writes the same in-memory structure as an npz cache.

**Tech Stack:** numpy, h5py (lazy), Julia 1.13.1 + Quoll.jl @ f26de28 (ingestion only).

**Spec:** `docs/dev/specs/2026-11-16-hamiltonians-design.md` §3 (`orbitals.py`, `cg.py`), §4.

## Global Constraints

- `h5py` is imported inside functions only (`tests/test_core_deps.py`).
- `ace_jax.ham` imports only the framework modules listed in `tests/test_ham_boundary.py`.
- Internal orbital order is m = −l..l of `eval/harmonics.py`; conversion happens at the IO boundary only.
- Committed fixtures are Quoll's bytes, under 4 MB in total, never edited by hand.
- No Julia in the main test job.

## Review Focus

1. A DeepH directory whose atoms of one species have different shell lists: refused with a clear error (Task 2 test).
2. A shell with l > 3: DeepH defines no order; refused, not guessed (Task 2 test).
3. A wrong orbital order or sign: must be detected by a test on real data, not by inspection (Task 2: the overlap two-centre test and its wrong-order counterpart).
4. A spinful directory (`info.json` `isspinful: true`): Task 4; until then the reader must not silently read it as non-spin (Task 4 adds the check).
5. A lattice given in rows instead of columns: `OperatorData.cell` is rows (ASE), files are columns; the bond-direction test fails if they are mixed.
